# PEPSI — sitio corporativo conceptual

## Publicar en GitHub Pages
1. Crea un repositorio en GitHub.
2. Sube `index.html` a la raíz del repositorio.
3. Entra en **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona `main` y `/ (root)`, guarda y espera el enlace publicado.

## Personalización
- Las fotografías son enlaces a imágenes fotográficas alojadas en Unsplash; requieren conexión a Internet.
- El audio se inicia únicamente cuando el visitante pulsa **ACTIVAR MÚSICA**.
- El formulario es demostrativo y no almacena ni envía datos. Conecta Formspree, Netlify Forms o un backend para recibir consultas.
- Para uso comercial, sustituye las imágenes de referencia por recursos oficiales autorizados desde la biblioteca de medios de PepsiCo: https://www.pepsico.com/media
- Este diseño es un proyecto conceptual independiente y no representa un sitio oficial de PepsiCo.
